# Cargo Incident Manager 🚚📦

## 📌 Descrição
Aplicação front-end simples para **controle de avarias e extravios de cargas**.  
Permite registrar ocorrências, visualizar em tabela dinâmica e acompanhar indicadores básicos de risco no supply chain.  

## 🛠️ Tecnologias utilizadas
- HTML  
- CSS  
- JavaScript  

## ⚙️ Funcionalidades
- Cadastro de ocorrências (carga, tipo, descrição, data)  
- Visualização em tabela com cores para cada tipo de incidente  
- Contador de avarias e extravios  
- Filtros por número da carga ou tipo de ocorrência
