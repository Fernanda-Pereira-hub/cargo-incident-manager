# Cargo Incident Manager

## 📌 Objetivo do Projeto
O **Cargo Incident Manager** é um software voltado para empresas que desejam monitorar, analisar e gerenciar informações relacionadas às suas operações logísticas.  
O objetivo é centralizar dados de **cargas, avarias, extravios, desempenho de transportadoras e indicadores de risco**, oferecendo uma visão clara e confiável para equipes de Supply Chain, Security e Risk Management.

A proposta do sistema é permitir que os usuários:
- Registrem ocorrências de avarias e extravios.  
- Acompanhem o histórico de incidentes por carga, rota ou transportadora.  
- Avaliem o nível de segurança das transportadoras por meio de scores.  
- Identifiquem padrões de risco e oportunidades de melhoria operacional.  
- Tenham acesso rápido e organizado às informações essenciais para tomada de decisão.

O projeto busca simular um ambiente real de gestão logística, aproximando o desenvolvimento de software das necessidades práticas de empresas que lidam com transporte, armazenagem e segurança de cargas.

## 🛠️ Tecnologias Utilizadas
Este projeto será desenvolvido utilizando tecnologias acessíveis e adequadas para construção de interfaces funcionais e sistemas orientados a dados:

**Front-end**
- HTML  
- CSS  
- JavaScript  

**Ferramentas e Recursos**
- Git & GitHub  
- Visual Studio Code  
- JSON para armazenamento inicial de dados  
- Power BI (possível integração futura para dashboards)  

**Possíveis evoluções**
- Banco de dados relacional (PostgreSQL ou MySQL)  
- Framework front-end (React)  
- API para comunicação entre módulos  
- Autenticação de usuários  
- Exportação de relatórios

## 📘 O que foi aprendido com a experiência
O desenvolvimento do **Cargo Incident Manager** proporcionou aprendizados importantes relacionados à construção de sistemas aplicados ao contexto logístico e de segurança operacional:

- **Modelagem de dados logísticos:** compreender como estruturar informações de cargas, transportadoras e incidentes de forma organizada e escalável.  
- **Desenvolvimento de interfaces funcionais:** criar telas intuitivas para registro, consulta e análise de ocorrências.  
- **Lógica aplicada a processos reais:** transformar rotinas de Supply Chain em funcionalidades práticas dentro do software.  
- **Gestão de riscos:** entender como indicadores, scores e histórico de incidentes podem apoiar decisões estratégicas.  
- **Boas práticas de versionamento:** utilizar Git e GitHub para organizar o ciclo de desenvolvimento.  
- **Pensamento orientado a produto:** planejar evoluções, funcionalidades futuras e melhorias contínuas.  
- **Visão de arquitetura:** compreender como diferentes módulos (cadastro, análise, relatórios) se conectam para formar um sistema completo.
